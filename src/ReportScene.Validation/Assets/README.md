# Color glyph fixture

`ColorGlyphFixture.ttf` is original test data generated by
`scripts/generate-color-glyph-fixture.py` under the repository license. It is not
derived from an external font.

The private-use character U+E000 consists of a red COLR layer on the left and a
COLR foreground-color layer on the right. Tests can distinguish intrinsic color,
the requested text foreground, and paint opacity without depending on installed
system fonts. The checked-in font is used directly; fontTools is required only
to regenerate it.
