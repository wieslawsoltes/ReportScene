# Deterministic glyph fixtures

`ColorGlyphFixture.ttf` and `OutlineGlyphFixture.ttf` are original test data generated by
`scripts/generate-color-glyph-fixture.py` under the repository license. It is not
derived from an external font.

In the color face, private-use U+E000 consists of a red COLR layer on the left and
a COLR foreground-color layer on the right. U+E001 maps an ordinary rectangular
outline in the same color-capable face. A -400-unit kerning pair between two
U+E000 glyphs produces overlapping shaped glyphs, distinguishing per-glyph
source-over opacity from one opacity layer around the entire run. The face uses
1000 units per em, a 1000-unit advance and 800-unit-high geometry.

The outline-only face retains those original shapes and positioning but removes
COLR/CPAL. It verifies that ordinary text preserves the native vector drawing path.
Tests load faces through a per-instance resolver, without modifying global font
fallbacks or depending on installed system fonts. The suite checks GPU coverage,
native drawing, clipping/transforms, PDF transparency groups and embedded SVG/HTML
PNG colors at multiple alpha values and resolutions.

Normal builds use the checked-in fixtures directly. fontTools is needed only to
regenerate them; fixed OpenType timestamps keep the generated bytes reproducible.
